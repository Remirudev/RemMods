## Windows review

- W1 blocker · Trash can permanently delete via a shell dialog; verbatim prefix stripped; delete not all-or-none — ACCEPT. The NukeOnDelete CI test stays with its registry layout UNVERIFIED; a deterministic `\\localhost\C$` case is added (that the sink sees no recycle flag there is UNVERIFIED until the first windows-2025 run).
- W2 blocker · custom manifest drops the Common-Controls v6 dependency — ACCEPT. Verified tauri-build 2.7.4 `lib.rs:327` warning and `windows-app-manifest.xml` (it contains only Common-Controls v6), and dialog 2.8.4 → rfd ^0.17 with `common-controls-v6`. `app.manifest` is dropped and the default kept; a build.rs content check is unnecessary without a custom manifest, and the smoke job catches regressions.
- W3 major · src-tauri test binaries lack the manifest — ACCEPT, other mechanism. Verified tauri-build calls `res.compile()` (bins only) and tauri-winres 0.3.7 documents `compile_for_everything` for exactly this case; Cargo's docs leave the scope of `rustc-link-arg-tests` for lib unit tests undefined (UNVERIFIED). Took A1's route instead of `/MANIFESTINPUT` link args: src-tauri has no Rust tests (`test = false`), DTO/AppError tests move to the new Tauri-free `remmods-ipc` crate, and bindings come from `[[bin]] export-bindings` with `required-features` (bins get the manifest; tauri-cli's own test `get_binaries_ignores_src_bin_with_disabled_required_features` shows it is not bundled).
- W4 major · nothing starts the app on Windows; on_navigation blanks release windows — ACCEPT. Verified Tauri's `on_navigation` doc example (`url.scheme() == "tauri"`), Windows custom protocols as `http://<name>.localhost` (`tauri-webview-mod.rs:1986`) and wry's `args.SetCancel(!allow)`. → `os/navigation.rs` allows the runtime origin; a required `smoke` job on both OSes from P0. Done with an in-app `--smoke` self-test rather than tauri-driver (the reviewer allowed either), because the same flag also tests installed packages (L4).
- W5 major · folder renames fail under antivirus/indexer handles; 1.6 s too short; holder text wrong — ACCEPT. Verified Microsoft FILE_RENAME_INFORMATION ("A directory cannot be renamed if it or any of its subdirectories contains a file that has open handles"). Separate budgets (files ≤1.6 s, folders ≤30 s with Cancel), AccessDenied on folder renames → `FolderBusy`, Restart Manager names the holder, Logic batches rename the folder first, CI test with a share-compatible handle. The rustup/graceful-fs budgets are cited from the review, not re-checked.
- W6 major · unsigned builds vs Smart App Control; signing later breaks the updater `.sig` — PARTLY. Verified Microsoft's SAC page (no per-app bypass; it can now be enabled without a clean install) and tauri-cli running `sign_updaters` after `bundle_project`. Accepted: README warning, Microsoft file submission, signing only via `bundle.windows.signCommand`. Rejected "apply to SignPath now": signpath.org/terms require a project "already released in the form that should be signed" and a verifiable reputation. Rejected the phased external-signing fallback: tauri-bundler 2.10.4 `bundle.rs` patches the main exe per package type before signing, so an exe signed before `tauri bundle` gets modified. Certum and SignPath's solo/`signCommand` fit stay UNVERIFIED.
- W7 minor · the updater's `exit(0)` kills running work — ACCEPT. Verified `updater.rs:1050` (`std::process::exit(0)`) and `on_before_exit` (line 403). `update_install` holds the OpGate, refuses during a job or open journal entry, flushes in `on_before_exit`.
- W8 minor · Linux test assumptions break on windows-2025 — ACCEPT. Canonicalised TempDirs plus an 8.3 Scope test; deterministic walk count with the timing gate on Linux only; fake-clock debounce plus one real watcher test; registry Steam paths normalised and deduped with same-file. The lowercase SteamPath form is third-party evidence, marked UNVERIFIED and added to the Windows-machine P1 checks.
- W9 minor · Windows JSON writers emit CRLF and escape HTML characters; the LF rule rewrites golden files — ACCEPT (merged with A9). RemMods writes LF and escapes non-ASCII and HTML-sensitive characters as `\uXXXX`; readers accept CRLF too, golden tests compare parsed values, fixtures are `-text`.
- W10 minor · zip entries with `\` separators — ACCEPT. APPNOTE 4.4.17.1 says so and Windows-made archives carry them; `\` is a separator in every format, with `Cool\x.pak` and `..\evil.pak` fixtures.
- W11 minor · the standalone exe lacks notices and WebView2 handling — ACCEPT (the reviewer's alternative). Standalone exe dropped from v1 (no WebView2 bootstrap, no update path, unsigned); notices embedded with `include_str!` for every package; a `tauri::webview_version()` check (wry calls GetAvailableCoreWebView2BrowserVersionString; verified in wry source) shows a native message.

## Linux review
